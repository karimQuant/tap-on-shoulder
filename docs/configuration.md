# Configuration

> [!WARNING]
> **Proposed.** These keys and defaults are design decisions. They are not a working interface yet.

The configuration lives in `~/.config/tap-on-shoulder/config.toml`. A project can override it with its own file. `tap config check` validates both.

```toml
[grace]                 # continuous waiting time before a tap, per category
question   = "5m"       # needs_decision
permission = "5m"       # needs_permission
blocked    = "5m"       # blocked (API error, missing credentials, …)

[alerts]
completion = false      # tap when a task finishes successfully?
info       = false      # tap on informational stops?
repeat     = "off"      # one tap per waiting episode; e.g. "30m" in a later release

[classifier]
mode = "model"          # model | rules
lean = "alert"          # when unsure, prefer tapping over staying silent

[notify.ntfy]
server    = "https://ntfy.sh"     # or your self-hosted server
topic     = "tap-<random>"        # generated by `tap setup`
token_env = "TAP_NTFY_TOKEN"      # optional access token, read from the environment
privacy   = "summary"             # summary | category-only
```

## Reference

| Key | Default | Meaning |
|---|---|---|
| `grace.question` | `5m` | Time a session must wait on a question before a tap |
| `grace.permission` | `5m` | Same, for permission prompts |
| `grace.blocked` | `5m` | Same, for errors and external blockers |
| `alerts.completion` | `false` | Also tap when a task finishes |
| `alerts.info` | `false` | Also tap on informational stops |
| `alerts.repeat` | `off` | Re-notify interval for the same episode (later release) |
| `classifier.mode` | `model` | `rules` turns off the embedded model |
| `classifier.lean` | `alert` | What to do when the classifier is unsure |
| `notify.ntfy.server` | `https://ntfy.sh` | ntfy server URL |
| `notify.ntfy.topic` | random | Your topic. On public servers it works like a password |
| `notify.ntfy.token_env` | unset | Environment variable that holds an ntfy access token |
| `notify.ntfy.privacy` | `summary` | `category-only` leaves the summary out of the notification |

## Environment variables

| Variable | Purpose |
|---|---|
| `TAP_GRACE_OVERRIDE` | Overrides every grace period, e.g. `10s` for testing |
| `TAP_NTFY_TOKEN` | ntfy access token, if you set `token_env` to this name |

Secrets never go in the config file. Reference them through environment variables instead.
