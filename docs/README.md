## Conventions used in these docs

- **Verified** means confirmed in official Claude Code documentation, with a link.
- **Proposed** means a design decision that hasn't been built yet.
- **Unverified** means an assumption we still need to test against real Claude Code.

Found something unclear? [Open an issue](https://github.com/karimQuant/tap-on-shoulder/issues). Small doc fixes are perfect first contributions.
